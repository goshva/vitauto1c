Внешняя печатная форма «Заказ-наряд (ВИТ)»
==========================================

Файл: zn-vit.epf
Документ: Заказ-наряд (автосервис). Типовая печать не меняется — появляется новый пункт
в меню «Печать»: «Заказ-наряд (ВИТ)».
Пример печати: example-NF-1.pdf (заказ-наряд НФНФ-000001 на зеркале, 22.10.2026).

Что сделано по пометкам заказчика
- Шапка: год выпуска — только год, без пробега; «Заявка» вместо «Вид ремонта»;
  «Дата окончания» вместо «Диспетчер»; без «в валюте / руб.».
- Работы: «Наименование работ» без артикула; колонки Ед. изм. (шт.) | Кол-во | н/ч | Цена | Сумма;
  без «Итого работ» и «В т.ч. НДС»; «Всего работ, руб.» — ячейкой под таблицей.
- Товары: отдельная колонка «Артикул»; Ед. изм. перед Кол-во; без «Итого» и «В т.ч. НДС»;
  «Всего, руб.» — ячейкой под таблицей.
- Без колонок скидки, без «Плательщика», «Причины обращения», гарантий и рекомендаций.
- Итог: «Итого по заказ-наряду, руб.» и «В том числе НДС, руб.».
- Внизу — текст из Word-файла заказчика: стоимость с суммой прописью и НДС, «Претензий по
  комплектности не имею…», подписи ИСПОЛНИТЕЛЬ / ЗАКАЗЧИК, дата.

Откуда берутся данные
- Заявка: номер и дата документа-основания; если его нет — номер заказ-наряда и дата начала работ.
- Дата окончания: поле «Дата окончания» заказ-наряда.
- Кол-во работ: Количество × Норма. Цена работ: из документа, а если там 0 — Сумма / Кол-во.
- Ставка НДС в тексте: из строк документа (если ставок несколько — просто «НДС»).
- Исполнитель: краткое наименование организации; должность и ФИО — из «Подписи руководителя»
  в заказ-наряде, иначе из карточки организации. Если не заполнено — пустая строка под подпись.
- Заказчик: полное наименование заказчика из документа.

Как подключить (рабочая база)
1. Скопировать zn-vit.epf на компьютер, с которого работаете в 1С.
2. В 1С: Администрирование → Печатные формы, отчеты и обработки →
   «Дополнительные отчеты и обработки» (галка должна быть включена) → открыть список.
3. «Добавить из файла…» → «Продолжить» на предупреждении → выбрать zn-vit.epf.
4. Проверить: Наименование «Заказ-наряд (ВИТ)», Размещение «Заказ-наряды (автосервис)» →
   «Записать и закрыть».
5. Открыть список заказ-нарядов, выделить документ → кнопка с принтером → «Заказ-наряд (ВИТ)».

Обновить на новую версию: тот же список → выделить «Заказ-наряд (ВИТ)» → «Обновить из файла…».
Отключить: открыть карточку обработки → Публикация «Отключена».

Сборка из исходников
src\ЗаказНарядВИТ — исходники (модуль и макет), layout.json — описание макета.
1cv8.exe DESIGNER /F<пустая база> /LoadExternalDataProcessorOrReportFromFiles src\ЗаказНарядВИТ.xml zn-vit.epf

Открытые вопросы к заказчику
- Ед. изм. у работ всегда «шт.»? Кол-во = Количество × Норма — так ли?
- «Заявка» — номер/дата заказ-наряда или отдельного документа-заявки?
- НДС: документ сейчас считает 20%, в тексте будет «НДС 20%». Если нужно 22% — менять ставку
  в заказ-нарядах, печатная форма напечатает то, что посчитано.
- Если в настройке организации не заполнена «Подпись руководителя» — ФИО директора не печатается.
