Конфигуратор матрицы видимости и редактирования колонок — Витавто (1С:УНФ)

Прототип для настройки прав «Роль × Статус × Колонка» с сохранением в localStorage браузера. Не подключается к 1С, не содержит реальных данных. Рядом: интерактивный процесс, разбор БТ/ФТ, БТ, ФТ, протокол апрувов, карта протокола.

Как это увидит роль «» — пример строк таблицы (статус: )

Зелёные поля — доступны для редактирования, жёлтые — только для просмотра. Все колонки видны всем ролям. Галка «Документ подписан оригинал» (true) снимает защиту строки: поля становятся редактируемыми.
Правила заполнения полей (выпадающие списки, автоподстановка, расчёт)
    Настройки хранятся в localStorage браузера (ключ vitaauto_column_matrix_v1), не шифруются и не покидают этот компьютер. Для переноса правил в 1С используйте экспорт JSON. При изменении структуры матрицы увеличивайте номер версии в файле.
