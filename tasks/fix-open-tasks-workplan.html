Цель

Колонка «Номер отгрузки» (В2) — только чтение у всех ролей; значение появляется системно, без ручного ввода в АРМ.

Работы

  1. Зафиксировать источник номера (рекомендация задачи: номер расходной накладной при записи/проведении).
  2. Запись в НомерОтгрузки регистра по строкам заказа.
  3. UI: убрать/заблокировать ручной ввод номера (кнопка «Заполнить дату и номер…» — только дата или действие «сформировать отгрузку»).
  4. Приёмка по чеклисту shipment-number-system-fill.md (перенести описание в эту ветку при старте работ).

Принято (владелец)

  • Источник номера: РасходнаяНакладная.Номер (пишется при проведении РН в фоне).
  • Дата отгрузки остаётся ручной.
  • Приёмка по чеклисту shipment-number-system-fill.md — вручную на ИБ.

вне scope Править контракт lab process-api / PWA — отдельная работа разрабов lab, не эта пачка.
