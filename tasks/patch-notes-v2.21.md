# Patch notes: АРМЗакупокИПродаж v2.21

**Ветка:** `techdebt/arm-v2.21` — от `pwa-odata` (источник прод-дампа 16.10.2026) + влитая `review/arm-v2.15-code`.
**Версия:** v2.20 → **v2.21** (тех. долг P0, см. `tasks/techdebt-plan.md`).
**Артефакт:** `АРМЗакупокИПродаж_v2.21.cfe`, исходники `src/АРМЗакупокИПродаж_v2.21`, отличия `diff/АРМЗакупокИПродаж_v2.20__v2.21.*`.

## Изменения

- **Сумма строк заказа покупателя (P0-1).** `Арм_ДанныеЗакупокИПродажФон.ОбработатьЗаказыПокупателей`: при «В работу»
  по закупке строки заказа покупателя записывались с `Сумма = 0` (НДС и «Всего» считались от нуля). Теперь перед
  `РассчитатьСуммуНДСИВсего` заполняется `Сумма = Количество × Цена` — во всех трёх ветках (строки «в работу» при
  сплите, строки нового заказа после сплита, без сплита). Так же уже было в `ОбработатьЧистыеПродажиВФоне`.
- **Свойство «Версия» расширения (P0-2).** Было пустым — версию в базе нельзя было определить без выгрузки.
  Теперь `2.21` (Конфигуратор → Расширения → свойства; `РасширенияКонфигурации.Получить()[...].Версия`).
- **Обновление и откат (P0-3).** Новый `odata/update-arm-ext.ps1`: обновляет только расширение АРМ в серверной базе,
  без пересоздания БД. Перед загрузкой выгружает текущее расширение в `.cfe` (и делает `pg_dump` при `-PgPassword`),
  запрещает регламентные задания и завершает сеансы, после загрузки — `/CheckModules`. `-Rollback` загружает
  последнюю выгрузку. `odata/deploy-autoservice-pg.ps1` (полное переразвёртывание) не менялся: по умолчанию v2.15,
  пока v2.16+ не согласованы.
- **CHANGELOG.md** в корне — версии v2.15 → v2.21 со ссылками на patch notes.
