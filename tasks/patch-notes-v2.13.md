# Patch notes: АРМЗакупокИПродаж v2.13

**Ветка:** `dev`.  
**База:** v2.12 → **v2.13** (исправление: модуль прав не компилировался).  
**Артефакт:** `АРМЗакупокИПродаж_v2.13.cfe`  
**Исходники:** `src/АРМЗакупокИПродаж_v2.13/`  
**Отличия:** [diff/АРМЗакупокИПродаж_v2.12__v2.13.md](../diff/АРМЗакупокИПродаж_v2.12__v2.13.md)

## Проблема

В v2.11 и v2.12 у администратора (и у всех ролей) перестала работать правка колонок АРМ: ячейки выглядят
редактируемыми, но значение не сохраняется, двойной щелчок по «Номенклатура», «Количество», «Цена», «Партия»,
«Дата отгрузки» ничего не открывает, кнопки статусов падают с ошибкой.

**Причина.** Общий модуль `Арм_МатрицаПрав` (генерируется `tools/generate_arm_matrix_rights.py`, появился в v2.11)
объявлял свою функцию `ПобитовоеИ(Маска, Бит)`. В платформе 8.3 это имя глобальной функции, поэтому модуль не
компилируется:

```text
{ОбщийМодуль.Арм_МатрицаПрав.Модуль(171,9)}: Процедура или функция с указанным именем уже определена (ПобитовоеИ)
```

Модуль не инициализируется, и любой вызов `Арм_МатрицаПрав.МожноРедактироватьПоле` (через
`РегистрыСведений.Арм_ПраваПользователей.ОтказПоПравамНаПолеСтроки`) завершается ошибкой «Ошибка инициализации
модуля». На эту проверку завязаны все писатели полей формы АРМ (v2.11 T01/T02), поэтому правка сломалась целиком.
Python-тесты (76 → 81) сверяют тексты модулей и ошибку не ловили; конфигуратор (`/CheckModules`) — ловит.

## Исправление

| Объект | Изменение |
|---|---|
| `Арм_МатрицаПрав` | функция `ПобитовоеИ` → `БитРолиВМаске` (логика та же: бит роли в маске ячейки) |
| `tools/generate_arm_matrix_rights.py` | имя функции, tip → `v2.13`, каталог `src/АРМЗакупокИПродаж_v2.13` |
| `tools/test_arm_matrix_rights.py` | 82 теста (было 81): новый `test_no_platform_global_names` — процедуры и функции расширения не называются как глобальные функции платформы (на v2.12 падает) |

Остальные объекты не менялись: сборка — v2.12.cfe с частичной загрузкой одного модуля
(`/LoadConfigFromFiles … -files CommonModules\Арм_МатрицаПрав\Ext\Module.bsl`), формы и права не пересобирались.

## Не ошибка (по решению D1e, v2.11)

Администратору по-прежнему **недоступны** поля вне whitelist `ПоляИзменяемыеАдминистратором`: «Номер отгрузки»,
«Номер заказа», «Статус строки» (только кнопками), «№ шасси», «Кол-во в резерве», «Кол-во в пути», «Дата УПД»,
«№ УПД», «Дата поступления». Если администратор должен их править — нужно решение по whitelist.

## Приёмка (ручная, на TEST)

1. LoadCfg `АРМЗакупокИПродаж_v2.13.cfe` + UpdateDBCfg, безопасный режим выкл.
2. Администратор: правка в ячейке «Комментарий», «Покупатель», «Цена себестоимости» — значение сохраняется.
3. Администратор: двойной щелчок «Номенклатура», «Количество», «Партия», «Дата отгрузки» — открываются диалоги.
4. Менеджер: «Количество» в строке «Заказано» — отказ с текстом «Роль «Менеджер» не может менять поле…».
5. Журнал регистрации: нет «Ошибка инициализации модуля … Арм_МатрицаПрав».
