## Предложение MVP

**MVP = печать отгрузочной ведомости позже; сейчас — ничего не печатать и не рассылать.**

| Что | MVP | Позже |
|---|---|---|
| Отгрузочная ведомость (M12) | одна печатная форма по строкам со статусом «Подготовлено/Собран» выбранного заказа покупателя: № отгрузки, дата, заказчик, позиции (наименование, артикул, кол-во, ед. изм.), графы подписи. Макет (MXL/табличный документ) в расширении, команда в основной форме | автоподстановка по шаблону договора, электронная подпись |
| Сборочный лист (K3) | не в MVP | после ведомости |
| Уведомления (M8, M11, M17, M18/G8) | не в MVP; менеджер видит статусы в списке («Только с закупками», фильтры) | варианты: оповещение в интерфейсе 1С (`ПоказатьОповещениеПользователя` при смене статуса) → затем e-mail/мессенджер (требует настроек УНФ и согласования) |
| Акты возврата | не в MVP ([returns-e2e.md](returns-e2e.md)) | вместе с возвратами |

Принципы: печать — только чтение данных строк (без записи в регистр); права на команду печати — по роли (менеджер, кладовщик/снабжение, админ); без внешних каналов (SMTP, мессенджеры) без отдельного решения.
