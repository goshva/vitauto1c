# H01 Phase A — инвентарь «немых» колонок (v2.11)

Источник колонок: `ОписаниеКолонокПоМатрице()` в `Form.obj.bsl` (50 колонок, порядок матрицы).  
ACL: `Арм_МатрицаПрав` / `default-matrix.js` (вкладка **manager**, уровень **order**).  
«Editable (roles summary)» — роли, для которых **хотя бы в одном** статусе АРМ `МожноРедактироватьПоле` = Истина; отдельно отмечен **Администратор (D1e)**, если поле в `ПоляИзменяемыеАдминистратором()`.

Статус: **закрыт 06.10.2026** (H01 Phase B в v2.12). D11=**A** (личная отметка). Единственный mute S2 → `ПоляВводаПоACL`.

`ОтметкаСтроки`, `Номенклатура`, `Количество`, `Цена`, `Коэффициент`, `Партия`, `ВидУслуги`, `ФормаОплаты`, `ДатаОтгрузки`, `КомментарийКСтроке`.

`НомерШасси`, `КоличествоВРезерве`, `КоличествоВПути`, `ДатаУПД`, `НомерУПД`.
