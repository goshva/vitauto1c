# Задача: unlock строки по А3 «Документ подписан оригинал»

**Статус (05.10.2026):** вопросы закрыты дефолтами, код — в `src/АРМЗакупокИПродаж_v2.11` (T06, без новых изменений кода сверх v2.10/v2.11: проверено, что путь работает для не-админа). Ручная приёмка — [acceptance-v2.10.md](acceptance-v2.10.md) B6.

## Разрыв (as-is, v2.10)

- Единственная постоянная блокировка строки в форме `АС_АРМ2` — статус `ЗаблокированоФоном` (выражение `СтрокаЗаблокирована` в обоих динамических списках) плюс временная интерфейсная `СтрокаЗаблокированаИнтерфейс` (ключи из `&ВременноЗаблокированныеКлючи`).
- Поле `ДокументПодписанОригинал` (А3) **ничего не разблокирует** в выражениях блокировки списков.
- Отдельная «защита» по автору: `АвторСтроки` + `ОтметкаСтроки` (выбор строки пользователем). Чужую отмеченную строку другой пользователь не может отметить/снять (`ИнвертироватьФлагНаСервере`).

## Решения (закрытые вопросы)

| Вопрос | Решение (дефолт без остановок) |
|---|---|
| Что такое «защита» строки | **Занятость автором** (`АвторСтроки` заполнен — строка отмечена своим пользователем и чужим недоступна для отметки). Статусная блокировка `ЗаблокированоФоном` — техническая, А3 её не снимает |
| Какие статусы допускают unlock (А3) | Любой статус, в котором матрица даёт роли право на поле `doc_signed_original`: по вкладке manager это **«Отгружено»** и **«Возврат»** (маска 15 = менеджер, кладовщик/снабжение, главный механик, админ). Админ (D1e=B) — whitelist без привязки к статусу |
| А3 = Истина | Очищает `АвторСтроки` и `ОтметкаСтроки` (реализовано в `ЗаписатьПолеСтрокиАРМ`, без условия на роль — работает и для не-админа) |
| А3 = Ложь (обратное переключение) | **Защита не возвращается**: автор/отметка не восстанавливаются, строка остаётся свободной |
| Флаг А3 в `СтрокаЗаблокирована` / условное оформление | **Не вводим**: А3 ничего не блокирует и не разблокирует в списках; только снимает занятость автором |
| Кто переключает А3 в UI | Через общий путь T02: двойной щелчок → `ОбработатьВыборАдминистратора` → ACL роль × статус × поле (`ОтказПоПравамАРМ`) → `ЗаписатьПолеСтрокиАРМ` (повторная серверная проверка). Не-админ (менеджер, кладовщик/снабжение, главный механик) может переключать А3 там, где матрица разрешает; Клиент/Поставщик — нет; без записи в `Арм_ПраваПользователей` — нет (D1b) |

## Что сделано

- v2.10: в `ЗаписатьПолеСтрокиАРМ` при `ДокументПодписанОригинал = Истина` очищаются `АвторСтроки` и `ОтметкаСтроки`.
- v2.11 (T01/T02): запись поля идёт по ACL, а не «только админ». Поле входит в `ПоляРедактируемыеАдминистратором` (общий ввод, булево — переключается щелчком). Тесты `tools/test_arm_matrix_rights.py` проверяют: менеджер может править А3 в «Отгружено»/«Возврат», не может в «Черновик»; побочный эффект Истины не привязан к роли.
- Проверка `АвторСтроки` в `ИнвертироватьФлагНаСервере` и выборках «мои отмеченные» не менялась.
