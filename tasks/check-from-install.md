# Задание: проверить работоспособность АРМ с нуля — от установки до работы в форме

## Цель

Убедиться, что на машине разработчика всё поднимается одной цепочкой: установка 1С и базы → расширение `АРМЗакупокИПродаж` v2.7 → демо-данные (seed) → рабочая форма АРМ. Итог проверки — заполненная таблица результатов из раздела «Отчёт» и список найденных проблем.

Автоматически уже проверено: скрипты отрабатывают, расширение загружается и применяется, модули без синтаксических ошибок, seed создаёт 15 строк. **Не проверено ни разу — работа формы АРМ в режиме предприятия.** Это главная часть задания (шаг 5).

## Что нужно

- Windows 10/11, права администратора, интернет (дистрибутивы качаются с Яндекс.Диска, около 3,4 ГБ).
- Свободное место: около 7 ГБ на системном диске и около 11 ГБ на диске для архивов.
- Репозиторий `goshva/vitauto1c`, ветка `seed-data`.
- Комьюнити-лицензия 1С (developer.1c.ru) — активируется вручную при первом запуске.

Все команды — из папки репозитория, в PowerShell.

## Шаг 1. Место на диске

```powershell
.\install-1c.ps1 search -List
```

**Ожидается:** список прошлых установок и артефактов с размерами, в конце — свободное место по дискам. Ничего не удаляется.

Если места мало, запустить `.\install-1c.ps1 search` и выбрать, что удалить. Базы данных (жёлтые строки) в `all` не входят.

## Что известно заранее

- **Пользователи seed не могут войти в базу:** это записи справочника с ролью АРМ, без учётных записей. Проверка идёт под «Админ». Роли менеджера, кладовщика и остальные в этом задании не проверяются.
- **Новые статусы** («Резервирование», «Ожидаем поступление», «Возврат») выставляет только seed. Перевести строку в них из формы пока нельзя — это не дефект проверки.
- **Двойной щелчок по «Кол-во»** работает по старой логике партий и сумму себестоимости по новой формуле не пересчитывает.
- **Сумма продажи** считается от «Н0 Кол-во», а не от «К6 Кол-во (ФАКТ)», как записано в матрице: в базе «Кол-во (ФАКТ)» хранится текстом.
- **У каждого контрагента есть «Основной договор»** — его создаёт сама конфигурация.
