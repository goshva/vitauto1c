# Seed для АРМ 3.0: путь детали по процессам

**Ветка:** `seed-arm-3.0`.  
**Источник данных:** [seed/Шаблон деталей.xlsx](../seed/Шаблон%20деталей.xlsx) → `tools/seed_from_xlsx.py` → `seed/data.json`.  
**Целевая база:** чистая установка УНФ + расширение АРМ 3.0 (схема регистра v2.14 и новее; на старой схеме seed
откажет со списком недостающих полей).

## Что делает

Пять сценариев таблицы → пять заказов покупателя (`SEED-309-1…5`, покупатель «АВД», договор «235»), в каждом
заказе — строка на каждый шаг процесса. Поля строк АРМ — как в таблице (В, К, М, Н, О, Р, С, Т), Т1 — сценарий,
Т2 — «Шаг N «шаг таблицы» — узел/пояснение».

| № | Сценарий (Т1) | Шагов |
|---|---|---|
| 1 | Товар на складе | 8 |
| 2 | Основной: закупка → отгрузка | 13 |
| 3 | Контроль комплектации (с возвратом на перекомплектацию) | 16 |
| 4 | Отказ клиента при получении (возврат) | 10 |
| 5 | Поступление машины в ремонт: запчасть, работы, выдача авто | 22 |

## Шаг таблицы (Н5) → статус АРМ

| Шаг | Статус |
|---|---|
| новая | Черновик |
| в работе (работы) | В работе |
| Заказ поставщику | Заказано; с О5 «да» — Оплачено |
| Приемка УПД | Приходуется |
| Резерв, «М3 резерв автоматом» | Резервирование |
| Размещение по складам, Уведомление о приходе | На складе |
| Задание на комплектацию, Комплектация (сборочный лист) | Комплектуется |
| Контроль комплектации | Собран |
| Уведомление о готовности, Отгрузочная ведомость | Подготовлено |
| Отгрузка клиенту, Выдача в ремзону | Отгружено |
| Возврат товара, Приёмка / подготовка возврата | Возврат |
| Контроль документов | Выполнено |
| Печать комплекта документов и выдача авто | Завершено |

Прочие правила генератора: О3 `0.22` → форма оплаты «Безнал (НДС 22%)», `нал` → «Наличные»; О5 `да` → «Оплачено»;
`------` — пусто; Н3 `200/182` → 200; формулы О2/Р2 вычисляются по значениям строки; В9 «Дата отправки на сборку» —
у строк с деталью начиная с «Комплектуется» (дата заказа или поступления, что позже). Новый шаг в таблице без пары в
`STEP_STATUS` — ошибка генератора.

## Запуск

```text
python tools\seed_from_xlsx.py                          # после правки таблицы (нужен openpyxl)
.\seed-1c.ps1 -IbDir D:\1c\test_arm30 [-KeepSafeModeOff]
python -m unittest tools.test_seed_from_xlsx            # data.json актуален, статусы и поля есть в АРМ
```

первый запуск — 23 объекта, 69 строк АРМ, 0 ошибок; повторный — 0 новых объектов, 69 строк, 0 ошибок.
