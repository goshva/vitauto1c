# Алгоритмы проверок АРМ (стенд: файловая база + зеркало прода)

Только чтение и тестовые данные E2E; в прод ничего не ставится. Запуск всего набора — `D:\1c\e2e\run-checks.ps1`,
сверка данных — `tools/e2e/check-data.mjs <url standard.odata> <пользователь> [пароль]`.

|---|---|---|

## 4. Сверка данных (DATA) — `check-data.mjs`, по номенклатуре E2E и документам с 18.10.2026
| Код | Правило |
|---|---|
| DATA-1 | Строка документа: Сумма = Количество × Цена (±0,01) — ЗаказПокупателя, ЗаказПоставщику, Приходная, Расходная |
| DATA-2 | Ставка НДС по виду номенклатуры на дату ≥ 01.01.2026: Общая → 22%, Пониженная → 10%, БезНДС → «Без НДС» (seed-приход «E2E seed» не проверяется) |
| DATA-3 | СуммаНДС = Сумма × r / (100 + r) при «Сумма включает НДС», иначе Сумма × r / 100 (±0,01) |
| DATA-4 | Документы, созданные АРМ (не помеченные на удаление), проведены |
| DATA-5 | Строки АРМ продажи: Себестоимость = Количество × Себестоимость единицы; Цена = Себест. ед. × Коэфф (±0,01), если коэффициент задан |
| DATA-6 | Статус ↔ документ: Заказано и дальше → есть заказ поставщику; Отгружено → есть расходная накладная, и она проведена |
| DATA-7 | Остаток E2E на складе (ЗапасыНаСкладах) ≥ 0 |
| DATA-8 | Нет строк в статусе «Заблокировано» (зависшее фоновое задание) |

## 5. Детекторы известных ошибок (BUG) — выводятся как предупреждения
| Код | Что ловит | Статус |
|---|---|---|
| BUG-1 | НомерЗаказа в регистре АРМ ≠ номеру документа (обрезка до 10 символов) | известна, v2.22 |
| BUG-2 | Отмеченные строки, скрытые фильтром периода (заказ старше 30 дней) | известна, v2.22 |
| BUG-3 | ОстатокДляСтроки больше фактического остатка на складе (размножение по пустой партии) | известна, v2.22 |
| BUG-4 | Не проведённый заказ покупателя с ARM-строками без номенклатуры (сплит v2.19) | известна, v2.22 |
| BUG-5 | Цена продажи ≠ Себест. ед. × Коэфф: пересчёт остатков перезаписывает себестоимость единицы средней по остатку (при пустой партии — по всем приходам), цена остаётся от подбора | найдена этим прогоном, v2.22 / вопрос заказчику |

DATA-5 по цене проверяется только там, где себестоимость не перезаписана; расхождение уходит в BUG-5.
