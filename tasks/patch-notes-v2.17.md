## Приёмка (ручная, на тестовой базе)

1. Провести заказ в работу с закупкой у двух поставщиков, довести строки закупки до «Комплектуется», перевести в «Собран» —
   две приходные, в каждой строки только своего заказа поставщику, количество строк = числу строк закупки.
2. Отметить строки двух черновых заказов (один — с активным заказом поставщику), «Удалить выбранные заказы» — первый помечен
   на удаление, по второму сообщение «пропущен: по нему есть активные закупки».
3. Отметить в одном заказе строки «Черновик» и «В работе», удалить — заказ обрабатывается один раз, без повторных сообщений.
4. Ввод «Дата отгрузки» в АРМ (роль с правом) — подставляется дата сеанса.
