# Patch notes: АРМЗакупокИПродаж v2.15

**Ветка:** `arm-v2.15` (от `dev`).  
**База:** v2.14 → **v2.15**: ошибка при закрытии программы с открытым АРМ.  
**Артефакт:** `АРМЗакупокИПродаж_v2.15.cfe`  
**Исходники:** `src/АРМЗакупокИПродаж_v2.15/`  
**Отличия:** [diff/АРМЗакупокИПродаж_v2.14__v2.15.md](../diff/АРМЗакупокИПродаж_v2.14__v2.15.md)

## Ошибка

`report.json` от 08.10.2026 14:25 и журнал регистрации (`_$PerformError$_`, 13:48:56):

```text
{АРМЗакупокИПродаж Обработка.АС_АРМ2.Форма.Форма.Форма(4004)}: Ошибка при вызове метода контекста (ЗаписатьИсключениеКлиента)
по причине: Серверные вызовы при завершении работы запрещены
```

Если закрыть программу целиком (а не окно АРМ), платформа вызывает `ПередЗакрытием` формы с
`ЗавершениеРаботы = Истина`, и в этот момент серверные вызовы запрещены. `ПередЗакрытием` вызывал сервер
(`СброситьФлагиНаСервере`), получал исключение и пытался записать его в журнал — это тоже вызов сервера, поэтому
падал и обработчик исключения: пользователь видел окно ошибки, флаги строк (`ОтметкаСтроки`/`АвторСтроки`) не снимались.
Правки данных в АРМ ошибка не затрагивала — они записываются сразу при вводе.

## Исправление

| Где | Изменение |
|---|---|
| Форма АРМ `ПередЗакрытием` | при `ЗавершениеРаботы = Истина` — выход до любых серверных вызовов |
| Форма АРМ `ПриСозданииНаСервере` | первым шагом `СброситьФлагиНаСервере()` — снимает флаги, оставшиеся после закрытия программы |
| `tools/generate_arm_matrix_rights.py` | `VERSION_DIR_GLOB` → v2.15 (матрица не менялась, модуль прав совпадает с v2.14) |
| `tools/test_arm_matrix_rights.py` | 94 теста (было 92): порядок проверок в `ПередЗакрытием`/`ПриСозданииНаСервере`, v2.15 меняет только форму |

Сборка: v2.14.cfe + частичная загрузка одного файла выгрузки XML (модуль формы `АС_АРМ2.Форма`).
