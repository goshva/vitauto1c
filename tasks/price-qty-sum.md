# Задача: цена × количество → сумма (показ админу)

Ветка: `arm-price-qty-sum` (от `seed-data` @ `aa15124`).  
База расширения: `АРМЗакупокИПродаж_v2.7` → результат **v2.8**.  
Основание: диалог 02.10.2026 — «просто цены запили, чтобы админ видел сумму».  
Единицы измерения (шт/л) и косметика seed — **вне scope**.

## Цель

Админ в таблице продаж меняет **количество** или **цену** — сразу видит пересчитанную **сумму** (себес. и продажа). Работает и для строк без остатка / ещё не купленных.

## Что уже есть в v2.7

| Путь | О2 (сумма себес.) | Р2 / коэфф | Р3 (сумма продажи) |
|---|---|---|---|
| Inline `ПриИзменении` → `ЗаписатьПолеСтрокиАРМ` → `ПересчитатьЦеныСтрокиАРМ` | да, при `Количество` / `СебестоимостьЕдиницы` | да | в запросе списка: кол-во × цена (или норма-час × цена) после refresh |
| Dblclick цена / коэфф → `ИзменитьЦенуНаСервере` / `ИзменитьКоэффициентНаСервере` | нет (не трогает О2) | да | refresh |
| Dblclick кол-во → `ИзменитьКоличествоНаСервере` | **нет** — дырка | — | refresh по старому Кол-во в регистре до… кол-во пишется, О2 не пересчитывается |

Формулы (канон матрицы / комментарий в коде):

- `О2` = `О1` × `Н0` (`Себестоимость` = `СебестоимостьЕдиницы` × `Количество`)
- `Р2` = база × `Коэффициент` (база = РРЦ или О1); при ручном Р2 — коэфф обратно
- `Р3` в списке = норма-час × цена, иначе количество × цена

## План реализации

### 1. Закрыть дырку dblclick «Кол-во»

Файл: `src/…_v2.7/…/Форма/Form.obj.bsl` → копия/пакет в v2.8.

В контуре **продажи** (`ИзменитьКоличествоНаСервере`, ветка «не закупка», ~2280): после `Запись.Количество = …` вызвать:

```
ПересчитатьЦеныСтрокиАРМ(Запись, "Количество");
```

перед `Набор.Записать()`.

В контуре **закупки** — только там, где количество строки реально меняется и строка сохраняется (ручная правка / уменьшение); при «увеличении через дельту» исходная строка кол-во не меняет — пересчёт не нужен. Новые split-строки с `Цена = 0` — О2 станет 0, ок.

### 2. Согласовать путь «цена себес.»

При изменении `СебестоимостьЕдиницы` через админский ввод О2 уже пересчитывается. Убедиться, что dblclick/выбор по О1 (если есть отдельный обработчик) тоже зовёт `ПересчитатьЦеныСтрокиАРМ(..., "СебестоимостьЕдиницы")`. Если отдельного пути нет — только inline, этого достаточно для демо.

### 3. Упаковка

- src `АРМЗакупокИПродаж_v2.8` + `АРМЗакупокИПродаж_v2.8.cfe`
- `diff` v2.7 → v2.8
- краткая пометка в `tasks/price-qty-sum.md` / при необходимости строка в matrix-task

### 4. Приёмка (ручная, в ИБ после LoadCfg v2.8)

Роль администратор АРМ, seed-строки:

1. Меняю **Н0 Кол-во** inline → **О2** и **Р3** обновились.  
2. Меняю **Кол-во** двойным щелчком → **О2** и **Р3** обновились (регресс дырки).  
3. Меняю **Р2 Цена продажи** → **Р3** обновилась; коэфф пересчитался при ненулевой базе.  
4. Меняю **О1** → **О2** = О1×Н0; при ненулевом коэффе — **Р2** по формуле.  
5. Строка без остатка / «ещё закупить» — суммы всё равно считаются от введённых цены и кол-ва.

Не трогаем: ед. изм., бинарную логику, seed «нули в ПП», merge в `dev`/`seed-data` без ок владельца.
