# Т10. Права ролей

**Под кем:** arm.storekeeper, arm.mechanic, arm.supply (и сверка с arm.manager)
**Время:** ~20 минут
**Что проверяем:** «Заказать», «Провести заказ» и «Вычеркнуть товар» доступны только менеджеру и администратору. Остальным — понятный отказ, данные не меняются.

Перед началом прочитай разделы 1–2 в [README](README.md).

## Ожидаемая матрица

| Действие | manager | admin | storekeeper | mechanic | supply |
|---|---|---|---|---|---|
| «Заказать» | можно | можно | отказ | отказ | кнопки нет |
| «Провести заказ» | можно | можно | отказ | отказ | кнопки нет |
| «Вычеркнуть товар» | можно | можно | отказ | отказ | кнопки нет |
| «Собран» для продажи со склада | можно | можно | можно | — | — |
| Статусы снабжения (Оплачено … Собран) | — | можно | — | — | можно |
| Правка полей | по матрице | всё | по матрице | по матрице | по матрице |

«Отказ» — кнопка есть, но после нажатия сообщение «Действие доступно менеджеру и администратору АРМ.» Если кнопки нет совсем — это тоже OK, запиши «кнопки нет».

## Данные

- Закупка «Черновик»: **Колодки в РУЧН-К1** (заказ НФНФ-000379, строка «Книга по ТО», в которой подобраны Колодки).
- Строка «В работе» для вычёркивания: **Фильтр в РУЧН-К4**. Осторожно: вычеркнутую строку вернуть нельзя. Если она вычеркнется — это и есть ошибка теста.

Запиши до начала: статус закупки Колодок и статус Фильтра К4.

## Шаги

### 1. arm.storekeeper

1. Войди под `arm.storekeeper`, открой АРМ. «Отменить выделение всех».
2. Найди `РУЧН-К1`, отметь закупку Колодок → «Заказать».

**Ожидаемо:** «Действие доступно менеджеру и администратору АРМ.» Закупка осталась «Черновик», заказа поставщику нет.

3. Сними флажок. Найди `РУЧН-К4`, отметь Фильтр → «Вычеркнуть товар».

**Ожидаемо:** предупреждение с текстом отказа. Строка не зачёркнута.

4. Отметь тот же Фильтр → «Провести заказ».

**Ожидаемо:** отказ, расходной накладной нет.

5. Сними флажок. Встань на любую строку продажи и попробуй изменить **Р2 «Цена продажи»** (двойной щелчок → новое число → Enter).

**Ожидаемо:** изменение не сохраняется, сообщение о правах. Нажми «Обновить» — цена прежняя.

6. Выйди («Файл → Выход»).

### 2. arm.mechanic

Повтори шаги 1.2–1.5 под `arm.mechanic`.

**Ожидаемо:** то же, что у кладовщика. Если у механика нет доступа к АРМ вообще — запиши это.

### 3. arm.supply

1. Войди под `arm.supply`. Открой «АРМ».

**Ожидаемо:** открылась форма снабжения. Кнопок «Заказать», «Провести заказ», «Вычеркнуть товар» нет. Есть «Оплачено», «Товар в пути», «Приходуется», «На складе», «Комплектуется», «Собран».

2. Попробуй изменить цену продажи (если колонка есть).

**Ожидаемо:** по матрице. Запиши, что получилось.

### 4. «Собран» для продажи у кладовщика

Проверено в [Т5](T05-otgruzka.md), шаг 2.3. Перенеси результат оттуда.
