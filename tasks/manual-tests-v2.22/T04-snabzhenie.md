# Т4. Снабжение: оплачено → приход → собран

**Под кем:** arm.supply, для проверки — arm.manager
**Время:** ~20 минут
**Что проверяем:** закупка проходит все статусы снабжения. На «Собран» создаётся и проводится приходная накладная с НДС 22%.

Перед началом прочитай разделы 1–2 в [README](README.md): как входить, выходить, как ставить флажок.

## Данные

Берём закупку **Диска из заявки РУЧН-К2** (заказ покупателя 00НФ-000004). Она уже заказана у «E2E Поставщик Альфа» по цене 1200.

Закупку Диска из РУЧН-К1 **не бери**: у неё цена в АРМ сброшена в 0 (известная ошибка 2).

## Шаги

### 1. Найти закупку

1. Войди под `arm.supply`. Открой «АРМ (закупки и продажи)» → «АРМ». Откроется форма снабжения.
2. Проверь период вверху: «Этот месяц» (или «Октябрь 2026», если сейчас ноябрь).
3. В поле поиска введи `РУЧН-К2`, Enter.
4. Найди строку: товар «E2E Диск тормозной…», поставщик «E2E Поставщик Альфа», статус «Заказано».
5. Запиши номер заказа поставщику из строки — пригодится для проверки.

**Ожидаемо:** строка есть, цена 1200, количество 1.

### 2. Статусы по очереди

Отметь флажком (самая левая колонка, один щелчок) **только эту строку**. Затем нажимай кнопки по одной. После каждой кнопки смотри на колонку статуса и запиши, что там.

| Шаг | Кнопка | Ожидаемый статус закупки |
|---|---|---|
| 2.1 | «Оплачено» | Оплачено |
| 2.2 | «Товар в пути» | Товар в пути |
| 2.3 | «Приходуется» | Приходуется |
| 2.4 | «На складе» | На складе |

Если после кнопки флажок снялся — поставь его снова перед следующей кнопкой.

**Проверка у менеджера (один раз, после 2.4).** Закрой 1С через «Файл → Выход». Войди под `arm.manager`, открой АРМ, найди `РУЧН-К2`, строку продажи Диска.

**Ожидаемо:** Н5 «Статус заявки» у продажи Диска совпадает со статусом закупки. Выйди и вернись под `arm.supply`.

### 3. «Комплектуется»

1. Отметь ту же закупку → «Комплектуется».

**Ожидаемо:** статус «Комплектуется». В колонке В9 «Дата отправки на сборку» — сегодняшняя дата.

### 4. «Собран» — главная проверка

1. Отметь ту же закупку → «Собран».
2. Если форма спросит дату частичного прихода — это значит, что пришло не всё. Запиши текст вопроса, ответь сегодняшней датой и отметь это в комментарии к тесту.

**Ожидаемо:** статус «Собран», сообщение без ошибок.

3. Выйди, войди под `arm.manager`, открой АРМ, найди `РУЧН-К2`.
4. Отметь **только** строку закупки Диска в нижней таблице → «Показать приходную накладную».

**Ожидаемо в приходной накладной:**
- документ проведён (зелёная галка / нет надписи «Не проведён»);
- поставщик «E2E Поставщик Альфа»;
- одна строка: Диск, количество 1, цена 1200;
- ставка НДС **22%**, сумма НДС **216,39**.

5. Закрой накладную (не меняй её). Посмотри строку продажи Диска в верхней таблице.

**Ожидаемо:** продажа Диска — «Собран» (готова к отгрузке).

6. Сними флажок с закупки.

### 5. Кнопка без отметок

1. Вернись под `arm.supply`. Нажми «Отменить выделение всех», чтобы флажков не осталось.
2. Нажми «Оплачено».

**Ожидаемо:** сообщение «Нет отмеченных…». Ни один статус не изменился (нажми «Обновить» и проверь).

## Итог

- **OK** — все ожидания совпали.
- **Ошибка** — любой шаг не совпал. Напиши номер шага, что увидел, приложи скриншот.

Не отгружай Диск в этом тесте — его отгрузка в Т5.
