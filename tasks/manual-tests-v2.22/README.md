## 1. Куда заходить

- **Где АРМ:** раздел «АРМ (закупки и продажи)» → «АРМ». У `arm.supply` эта же команда открывает форму снабжения.
- **Период** вверху формы — «Этот месяц». Все тестовые заказы созданы 19.10.2026. Если тест проходишь в ноябре, поставь период «Октябрь 2026».

## 2. Как работать с таблицами АРМ

В форме две таблицы. Верхняя — **Продажи**, колонки с кодами (А2, В4, М1, Н0…). Нижняя — **Закупки**. Она показывает закупки той продажи, на которой стоит курсор.

**Найти свои строки.** Встань в таблицу продаж и введи в поле «Поиск (Ctrl+F)» номер заявки, например `РУЧН-К3`, затем Enter. Если список не отфильтровался, щёлкни по любой строке и нажми кнопку «В конец» (⏬) справа под таблицей. Галка «Только с закупками» оставляет только строки, у которых есть закупка.

**Изменить значение:**
- Номенклатура (М1), поставщик (С1), договор: **двойной щелчок по ячейке** открывает список выбора. В списке найди нужное и выбери двойным щелчком или кнопкой «Выбрать».
- Количество, цена, коэффициент (Н0, О1, Р1, Р2, «Цена» в закупке): **двойной щелчок по ячейке** открывает окно «Введите …». Набери число (дробь через запятую: `1,3`) и нажми **Enter** или **ОК**.
- **Не нажимай F2** на строке АРМ. F2 открывает служебную запись регистра, и в ней можно случайно сломать связь с заказом. Если открыл — закрой крестиком и ответь «Нет».

**Строки перескакивают.** После каждой правки строка может уехать в другое место списка — это известная ошибка АРМ, см. раздел 4. Перед следующей правкой каждый раз проверяй по К4/К5 (наименование и артикул клиента), что стоишь на нужной строке.

**Отметка А1 (флажок).** Это самая левая узкая колонка в обеих таблицах.
- Ставится и снимается **одним щелчком** по этой колонке. Двойной щелчок ставит и тут же снимает.
- Если колонку не видно, щёлкни по строке и нажимай стрелку **←**, пока курсор не дойдёт до самого левого столбца. Когда курсор попадает на флажок, флажок переключается.
- Отметка личная: каждый пользователь видит свои флажки чёрными, чужие — серыми.

**Кнопки «Открыть заказ покупателя / поставщику / приходную / расходную»** открывают документы по **отмеченным** строкам, а не по строке под курсором. Чтобы открыть документ конкретной строки, отметь только её. Если отмечено несколько строк, откроется несколько документов.

**Перед каждым тестом сними все свои отметки.** Пройди по своим строкам или нажми «Отменить выделение всех» над таблицей. Старые флажки, в том числе в строках других заявок, попадают в «Заказать» и «Вычеркнуть».

## 4. Известные ошибки — повторно не заводить

1. **Вычеркнутую строку нельзя вернуть.** Кнопка «Восстановить товар» ничего не делает.
2. **Подбор товара в одной заявке сбрасывает в 0 цену уже заказанной закупки этого же товара в другой заявке** и меняет порядок строк. В заказе поставщику цена остаётся правильной.
3. **«Заказать» по отмеченной закупке может разделить заказ без вопроса «Выбраны не все позиции…».** Вопрос появляется, только если у заказа несколько закупок.

Если видишь именно это — в комментарии напиши «известная ошибка N».

## 5. Как записывать результат

- Итог каждого теста — **OK** или **Ошибка** — заноси в сводную таблицу документа «АРМ v2.22 — ручное тестирование».
- По ошибке укажи: тест и номер шага, что нажал, точный текст сообщения 1С, скриншот.
- Если 1С показала техническую ошибку, открой «Администрирование → Журнал регистрации», найди событие `АРМ.Ошибка` на это время и приложи текст записи.
- После ошибки нажми «Обновить» над таблицей и проверь, что данные не изменились. Если изменились — тоже напиши.
