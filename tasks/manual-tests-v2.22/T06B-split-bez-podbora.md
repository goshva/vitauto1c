# Т6Б. Разделение заказа, когда остаются строки без подбора

**Под кем:** arm.manager
**Время:** ~20 минут
**Что проверяем:** если заказать часть строк, а в остальных не выбран товар (М1 пустая), новый заказ создаётся без ошибки. В нём ровно столько строк, сколько осталось.

Перед началом прочитай разделы 1–2 в [README](README.md).

## Данные

Заявка **РУЧН-К3**, заказ покупателя 00НФ-000005. В ней 3 строки «В работе», ничего не подобрано. Её никто не трогал — используй только для этого теста.

## Шаги

### 1. Подобрать товар только в строку 1

1. Войди под `arm.manager`, открой АРМ, найди `РУЧН-К3`. Нажми «Отменить выделение всех».
2. Запиши, какие 3 строки есть (К4 — наименование клиента). Дальше «строка 1» — первая по К4.
3. В строке 1 двойной щелчок по **М1** → выбери «E2E Диск тормозной (под закупку, НДС общая)».
4. Заполни в строке 1 (двойной щелчок по ячейке → число → Enter):
   - Н0 = `1`
   - О1 = `1200`
   - Р1 = `1,3`

**Ожидаемо:** Р2 «Цена продажи» = 1560. В нижней таблице появилась закупка Диска (на складе его нет).

5. Строки 2 и 3 **не трогай**: М1 должна остаться пустой.

### 2. Заполнить закупку

1. Встань на строку Диска в верхней таблице. В нижней таблице на строке закупки:
   - «Поставщик» → «E2E Поставщик Альфа»;
   - «Договор» → «Договор поставки E2E»;
   - «Цена» → `1200`.

**Ожидаемо:** закупка в статусе «Черновик», поставщик, договор и цена видны.

### 3. Заказать

1. Отметь **только закупку** Диска (флажок в нижней таблице) → «Заказать».
2. Если появился вопрос «Выбраны не все позиции по заказам… Продолжить?» — ответь «Да». Если вопроса не было, запиши «вопроса нет — известная ошибка 3» и продолжай.

**Ожидаемо:**
- **нет** ошибки «Номенклатура не может быть пустым»;
- сообщение «Заказы поставщикам оформлены (заказов покупателей: 1)»;
- Диск и его закупка — «Заказано».

### 4. Проверить новый заказ

1. Найди снова `РУЧН-К3`. Строки 2 и 3 теперь в **новом** заказе: в колонке В4 у них другой номер.
2. Запиши номер нового заказа.

**Ожидаемо:**
- по новому заказу в АРМ **ровно 2 строки**, а не 4;
- в старом заказе 00НФ-000005 остался только Диск.

3. Отметь только строку 2 → «Открыть заказ покупателя».

**Ожидаемо:** документ записан, но **не проведён**. В табличной части 2 строки. Закрой, ничего не меняя.

### 5. Подобрать оставшиеся строки и отгрузить одну

1. Строка 2: М1 → «E2E Фильтр масляный (без НДС)», Н0 = `1`, Р2 = `600`.
2. Строка 3: М1 → «E2E Книга по ТО (НДС 10%)», Н0 = `1`, О1 = `300`, Р1 = `1,3` (Р2 станет 390).

**Ожидаемо:** у строк нет закупок (товар на складе), либо закупка появилась — тогда запиши.

3. Отгрузи **Фильтр** по шагам 2–4 из [Т5](T05-otgruzka.md): резервирование → комплектуется → (кладовщик) «Собран» → «Ввести дату и номер отгрузки» (сегодня, `ОТГ-3`) → отметить только Фильтр → «Провести заказ».

**Ожидаемо:** сообщение «…расходные накладные оформлены: 1». Новый заказ покупателя стал проведённым. В расходной только Фильтр, 1 × 600, без НДС.

## Итог

- **OK** — нет ошибки про пустую номенклатуру, 2 строки в новом заказе, заказ провёлся при отгрузке.
- **Ошибка** — укажи шаг и текст сообщения.
