# Т11. Проверки и ошибки

**Под кем:** arm.manager
**Время:** ~30 минут
**Что проверяем:** АРМ не даёт оформить некорректные данные и понятно пишет, что не так. После каждого отказа данные не меняются.

Перед началом прочитай разделы 1–2 в [README](README.md).

**Правило для всех шагов:** после каждого отказа нажми «Обновить» над таблицей. Статусы и значения должны остаться прежними, новых документов быть не должно. Если что-то создалось или изменилось — это **Ошибка**, приложи текст сообщения.

## Данные

Загрузи новую заявку **РУЧН-К9** (README, раздел 3). Строки:
- строка 1: М1 → Диск, Н0 = `1`, О1 = `1200`, Р1 = `1,3`. Закупка: Альфа, «Договор поставки E2E», Цена `1200`;
- строка 2: М1 → Фильтр, Н0 = `1`, Р2 = `600`;
- строка 3: М1 **пустая** (не подбирай).

Перед каждым шагом — «Отменить выделение всех».

## Шаги

### 1. Закупка без поставщика

1. В закупке Диска К9 очисти «Поставщик» (двойной щелчок → выделить → Delete → Enter, или кнопка очистки ×).
2. Отметь закупку → «Заказать».

**Ожидаемо:** заказ не оформлен. В сообщении указана строка и причина — нет поставщика.

3. Верни поставщика Альфа.

### 2. Нулевая цена

1. В закупке Диска поставь «Цена» = `0`. Отметь → «Заказать».

**Ожидаемо:** отказ со списком ошибок, ничего не оформлено.

2. Верни цену `1200`.

### 3. Нулевое количество

1. В закупке Диска поставь «Количество» = `0`. Отметь → «Заказать».

**Ожидаемо:** отказ с понятной причиной. Верни `1`.

2. В строке Фильтра поставь Н0 = `0`. Отметь Фильтр → «Провести заказ».

**Ожидаемо:** отказ, расходной нет. Верни Н0 = `1`.

### 4. Несопоставленный товар

1. Отметь строку 2 (Фильтр) и строку 3 (пустая М1) → «Провести заказ».

**Ожидаемо:** в сообщении «Товар не сопоставлен («…наименование клиента…»)». Вся пачка не проведена — Фильтр тоже не отгружен.

### 5. Ничего не отмечено

1. «Отменить выделение всех». Нажми «Заказать».

**Ожидаемо:** «Нет отмеченных строк…». Без ошибок, без документов.

2. Нажми «Провести заказ».

**Ожидаемо:** то же.

### 6. Два заказа в одном «Заказать»

1. Отметь закупку Диска в **РУЧН-К9** и закупку Колодок в **РУЧН-К1** (заказ НФНФ-000379). У Колодок должен быть поставщик и цена — если пусто, поставь Альфа, договор, Цена `800`.
2. «Заказать». На вопрос «Выбраны не все позиции…» — «Да».

**Ожидаемо:**
- сообщение «Заказы поставщикам оформлены (заказов покупателей: 2)»;
- каждая закупка привязана к своему заказу покупателя: отметь по одной → «Открыть заказ поставщику» и проверь, что там один товар.

### 7. Загрузка без обязательных полей

1. «Загрузить данные из Excel». Вставь строки из примера, но **не выбирай покупателя** → «Загрузить».

**Ожидаемо:** загрузка не начинается, сообщение называет поле «Покупатель».

2. Выбери покупателя из списка, **очисти договор** → «Загрузить».

**Ожидаемо:** сообщение про договор.

3. Верни договор, **очисти номер заявки** → «Загрузить».

**Ожидаемо:** сообщение про номер.

4. Закрой форму загрузки без загрузки.

## Итог

- **OK** — все проверки отказали с понятным текстом, ничего не создалось.
- **Ошибка** — укажи шаг, текст сообщения и что изменилось.
