## 4. Общая схема по слоям

### 4.1 PostgreSQL

- Схемы: `auth` (пользователи, роли, `auth.user_warehouse`), `arm` (строки, статусы), `stock` (остатки), `doc`, `ref`, `imp`, `integration`, `sys` (журнал изменений для WS), `legacy`, `onec`.
- Матрица прав — данные, а не код: таблица прав «роль × статус × поле» должна грузиться из `default-matrix.js` через мигратор (или из `backend/internal/arm/matrix.json`). Бит роли хранится как поле; при отсутствии роли — отказ (fail-closed).
- Задачи:
  - P1. Добавить бит роли `supply` (или профиль) в `auth` и в матрицу; миграция `0013`.
  - P2. Таблица `auth.user_warehouse` — проверить ограничение складов для storekeeper и supply.
  - P3. `sys.change_log` (24 ч) для WebSocket с полями `seq`, `entity`, `version`, `by`.
  - P4. Версия строки (`version`) для `If-Match`.
  - P5. Миграция порта в документации: 5434 → 5432.
- Гейты: G2.1 (`goose status`), G2.2 (R1–R4, R7 = 0), G3.1 (R5, R6, R8 = 0), после 0013 — пересборка на копии `vitauto_dev`.

### 4.2 Go (`backend/`, `vitauto-api`)

- Слои: `internal/arm` (логика строк, `PatchLine`), `internal/domain` (матрица, статусы), `internal/api` (маршруты `/api/v1`), `internal/realtime` (WebSocket — этап 6).
- Middleware: аутентификация → роль(и) пользователя → проверка по матрице (`МожноРедактироватьПоле`) → склады (`auth.user_warehouse`).
- Ошибки: `403` при запрете поля, `409` при устаревшей версии (`If-Match`), `422` при нарушении статуса.
- Задачи по ролям: см. раздел 5.
- Гейты: G4.1 `go test`, G4.2 `arm-processes.e2e.js` на Go (35/37 и известные), G4.3 R9.

### 4.3 Vue (PWA)

- Выбор бэкенда — `session.baseUrl` (`/api` → Go, иначе OData) до этапа 11. Новый `src/http/backend.js` (этап 5), `VITE_BACKEND`.
- Меню, экраны и редактируемость полей строятся **по матрице, полученной от сервера**, а не по зашитым ролям в коде.
- Realtime (этап 6): `src/http/realtime.js` и Pinia-хранилище `realtime`; баннер конфликта, подсветка изменённых полей, перечитывание строки.
- Гейты: G5.1 vitest, G5.2 `npm run build`, G5.3 e2e на обоих бэкендах, G6.2 e2e r01–r05.
