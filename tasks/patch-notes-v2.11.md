- Не-админ редактирует поле только если матрица разрешает его роли поле **в текущем статусе строки**.

- `ЗаблокированоФоном` → правка запрещена всем.
- Кнопки статусов: manager + admin (D2); набор переходов MVP не расширялся (полный T03 — позже).

### Ручная проверка на TEST (T12a; роль «Менеджер»)

1. АРМ под менеджером (запись в `Арм_ПраваПользователей` есть) — форма открывается.
2. «Черновик»: Покупатель, Номенклатура, Количество, Цена, Коэффициент, Комментарий — сохраняются, суммы пересчитываются.
3. «Заказано»: Покупатель, Количество — отказ с текстом роль/статус/поле.
4. «Отгружено»: «Документ подписан оригинал» — да; Количество — отказ.
5. «Номер отгрузки» — не редактируется ни в одном статусе.
6. «Черновик» + «Статус: резервирование» — статус меняется.
7. «Заказано» + кнопка статуса — менеджеру отказ по `line_status`.
8. Пользователь **без** записи в регистре: просмотр OK, правка — «не задана роль».
9. «Клиент»: только «Комментарий к строке».
10. Администратор: whitelist в «Завершено»; кнопки статусов как в v2.10.
