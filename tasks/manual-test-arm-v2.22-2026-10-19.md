# Ручное тестирование АРМ v2.22 на зеркале — результаты (19.10.2026)

База: `localhost\vitauto_mirror` (зеркало прода), АРМ 2.22 + АРМ_OData 1.2, веб-клиент `/mirror`, пользователь arm.manager.
Сценарии — документ «АРМ v2.22 — ручное тестирование» (Т1–Т12). Пройдены Т1, Т2, Т3, Т6А, Т7; остальные не пройдены (см. внизу).

## Ошибки АРМ v2.22

1. **Вычеркнутую строку нельзя вернуть (Т7).** Кнопка меняется на «Восстановить товар», но ничего не происходит, сообщения нет.
   `Арм_ОбщегоНазначенияАРМ.ПолучитьМассивОтмеченныхКлючейСвязи` отбирает только `НЕ Т.Удаление`, поэтому зачёркнутая строка в `ВычеркнутьСтрокиПоКлючам` не попадает.
2. **Пересчёт по номенклатуре портит уже заказанную закупку.** Подбор Диска в РУЧН-К4/К2 сбросил у заказанной закупки Диска из РУЧН-К1 `Цена` 1200 → 0 и сменил `Порядок`; в заказе поставщику 157 цена осталась 1200.
   `Арм_ОбщегоНазначенияАРМ.УправлятьСтрокойЗакупки` пишет `Цена = 0` и новый `Порядок` в найденную закупку без проверки статуса «Заказано». Отсюда же «прыгающие» строки в списке.
3. **Сплит без подтверждения (Т6А).** `Арм_ДанныеЗакупокИПродажФон.СформироватьЗаказыФоновоеЗадание`: если отмечена закупка, «всего штук» считается по закупкам заказа, а не по продажам. В РУЧН-К2 закупка была только у Диска (1 из 1) → вопрос не задан, хотя заказ разделён. В Т3 вопрос был только потому, что у Колодок была вторая закупка («1 из 2»).

## Замечания

- Загрузка без строк: ошибки нет, но и сообщения нет — форма молча ничего не делает.
- Сообщение «Строка 2 пропущена: это заголовок таблицы» не видно — форма загрузки закрывается сразу после успешной загрузки.
- После уменьшения Н0 у Колодок в авто-закупке стёрся поставщик.
- F2 на строке АРМ открывает запись регистра с редактируемыми служебными полями (Документ заказ покупателя и др.) — можно случайно испортить связь.
- Вопрос сплита в Т3: «отмечено 1 шт. из 2 шт.», хотя в заказе 3 строки (следствие ошибки 3).
- Повторное «Заказать» по заказанной закупке: кнопка неактивна (вместо сообщения) — защита работает.

## Поправки в описание тестов

- «Открыть заказ покупателя/поставщику» открывает документы по **отмеченным** строкам пользователя, а не по текущей строке.
- Флажок А1 ставится одиночным щелчком по узкой колонке слева (или стрелкой «влево» на неё); двойной щелчок ставит и тут же снимает.
- Т2, Колодки: на зеркале свободный остаток в АРМ 0 (открытые заказы), деление «склад + закупка» не воспроизводится.

## Подготовка данных и уборка

- Загружены РУЧН-К1…К4 (00НФ-000003…000006).
- На зеркале были «висящие» отметки arm.manager от автотестов PWA (закупки 1005, 1007, 3021.2 и др.) — сняты; на конец сессии отметок нет.

## Не пройдено

Т4 (arm.supply), Т5 (arm.storekeeper), Т6Б (РУЧН-К3), Т8, Т9, Т10, Т11, Т12. Причина остановки: веб-клиент держит один сеанс, а браузерная панель не открывалась повторно.
