## 2. Правила ACL для «лишних» и непарных статусов

1. **Два значения АРМ → один статус матрицы** (`Подготовлено`/`Собран`, `Выполнено`/`Завершено`): права в матрице
   единые. Различие значений остаётся только в бизнес-логике кода (переходы, выборки), в ACL правки полей не различается.
2. **`ЗаблокированоФоном`** — технический статус на время фонового задания. `МатричныйСтатусПоСтатусуАРМ` возвращает `Неопределено`,
   `МожноРедактироватьПоле` → **Ложь для любой роли, включая Администратора** (v2.10 UI уже не давал править такие строки;
   в v2.11 запрет добавлен и на сервере в `ЗаписатьПолеСтрокиАРМ`).
3. **Неизвестное / пустое значение** статуса (`ПустаяСсылка`, будущие значения enum без записи в таблице) → запрет (fail-closed).
4. **Админ** (D1e = B): whitelist `ПоляИзменяемыеАдминистратором` без привязки к статусу матрицы; единственное исключение — п. 2.
5. **Снабжение** (D1d) → бит `storekeeper`; **Клиент** → `client`; **Поставщик** → `supplier`; **ГлавныйМеханик** → `chief_mechanic`.
6. Статус строки для проверки читается **на сервере из регистра** по `ИдентификаторЗаписи`, а не берётся из данных клиента.

## 3. Расхождения с кодом v2.10 (нужен ок — НЕ решено молча)

| # | Вопрос | Поведение в v2.11 (T01) |
|---|---|---|
| M1 | v2.10 разрешал правку не-админу только в `ВРаботе`/`Черновик`/`Собран`. Матрица даёт права по 15 статусам и по ролям. | ACL по матрице (вкладка manager, уровень order). Это **сужает** `Собран` и **расширяет** остальные статусы там, где матрица разрешает. |
| M2 | `Собран` vs `Подготовлено`: в коде v2.10 разные ветки (`Собран` — «собрано поставщиком», `Подготовлено` — «готово к отгрузке по заказу»). Матрица их не различает. | Оба = `ready_to_ship`. Если владелец захочет разные права — нужен новый статус в матрице (меняет канон). |
| M3 | `Завершено` vs `Выполнено`: аналогично, оба = `closed`. | Оба = `closed`. |
| M4 | Seed ставит для двойных статусов первый (`Подготовлено`, `Выполнено`). | Не влияет на ACL. |
| M5 | Статусы «Резервирование», «Ожидаем поступление», «Возврат» выставляет только администратор (v2.10 MVP) и seed; переходов для других ролей нет. | ACL их знает; переходы — T03/T10. |
