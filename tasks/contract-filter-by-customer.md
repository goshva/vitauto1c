# Задача: «Договор с заказчиком» — только договоры выбранного Заказчика

## Цель

В таблице продаж АРМ при выборе значения в колонке «Договор с заказчиком» показываются только договоры контрагента из колонки «Заказчик» той же строки. Договор другого контрагента выбрать нельзя. Если Заказчик не указан, форма выбора договора не открывается, и пользователь видит, что сначала нужно выбрать Заказчика.

## Откуда правило

`column-matrix (5).json`, `fieldRules`, правило 2 (в `index.html` — то же):

> Договор с заказчиком — только договоры выбранного контрагента (Заказчик).
> `{"type": "filter", "column": "contract", "by": "customer", "directory": "counterparties.contracts"}`

## Почему это поле первое

Из восьми правил матрицы в этом меньше всего логики. Это один отбор на одном поле, и в расширении для него уже всё есть:

- справочник `ДоговорыКонтрагентов` с владельцем-контрагентом;
- форма выбора `Справочник.ДоговорыКонтрагентов.Форма.ФормаВыбора`: в расширении она ставит недоступный для снятия отбор по параметру `Владелец`;
- готовый образец: договор поставщика в таблице закупок открывается так же, с `Владелец` = Поставщик (`ДанныеАРМОтображениеВыбор`, ветка `ДанныеАРМОтображениеЗакупкиДоговор`).

Остальные правила требуют больше:
- «Вид услуги» — это данные, а не логика;
- формулы цены и суммы пересекаются с текущим пересчётом цены;
- «одно из обязательно» требует решить, когда проверять;
- автозаполнение по госномеру требует справочника машин, которого нет.

## Текущее состояние (v2.1)

Проверено на копии базы `D:\1c\test_v21`, в ней v2.1.

- `Договор` (ресурс `Арм_ДанныеЗакупокИПродаж.Договор`, тип `СправочникСсылка.ДоговорыКонтрагентов`) показывается в таблице продаж. Администратор меняет его двойным щелчком через общий ввод значения `ПоказатьВводЗначения`. Отбора по Заказчику нет — доступны договоры всех контрагентов.
- `Покупатель` («Заказчик», тип `СправочникСсылка.Контрагенты`) администратор тоже меняет двойным щелчком.
- По матрице договор меняют в статусе «Новый» менеджер, кладовщик, главный механик и администратор, в статусах с «Заказано у поставщика» по «Готово к отгрузке» — автор строки. Сейчас в АРМ колонку правит только администратор. Права по ролям и статусам — не в этой задаче.

## Границы

**Входит:**
- отбор договоров по Заказчику строки при выборе в колонке «Договор с заказчиком» таблицы продаж;
- сообщение, если Заказчик не указан;
- проверка на сервере при записи: договор должен принадлежать Заказчику строки.

**Не входит:**
- что делать с уже выбранным договором при смене Заказчика — см. вопрос 1;
- права на колонку по ролям и статусам из матрицы;
- договор поставщика в таблице закупок — он уже работает с отбором по Поставщику, не трогать;
- остальные правила `fieldRules`.

## Что сделать

Модуль формы `Обработка.АС_АРМ2.Форма.Форма`, расширение `АРМЗакупокИПродаж`, версия **v2.2**.

1. **Выбор договора.** В `ОбработатьВыборАдминистратора()` для поля `Договор`, вместо общего `ПоказатьВводЗначения`:
   - если в строке не заполнен `Покупатель` — показать предупреждение «Сначала выберите Заказчика в этой строке» и не открывать форму;
   - иначе открыть `Справочник.ДоговорыКонтрагентов.Форма.ФормаВыбора` с параметрами `Владелец` = `Покупатель` строки, `РежимВыбора` = Истина, `ЗакрыватьПриВыборе` = Истина;
   - выбранный договор записать через `ПослеВводаЗначенияАдминистратором()` → `ЗаписатьПолеСтрокиАРМ()`, как остальные поля.
2. **Проверка при записи.** В `ЗаписатьПолеСтрокиАРМ()` для поля `Договор`: если значение заполнено и его `Владелец` не равен `Покупатель` записи — не записывать, вернуть текст «Договор «…» не принадлежит заказчику «…»». Пустое значение (очистка договора) разрешено.
3. **Версия.** Собрать `АРМЗакупокИПродаж_v2.2.cfe` из `src/АРМЗакупокИПродаж_v2.2` (копия v2.1 плюс эти изменения).

## Решение — АРМЗакупокИПродаж_v2.2.cfe (ветка `contract-filter-by-customer`)

Исходники: `src/АРМЗакупокИПродаж_v2.2`. Отличия от v2.1: `diff/АРМЗакупокИПродаж_v2.1__v2.2.md`.

- **Выбор.** В `ОбработатьВыборАдминистратора` для поля `Договор`: без Заказчика — предупреждение «Сначала выберите Заказчика в этой строке»; иначе `Справочник.ДоговорыКонтрагентов.Форма.ФормаВыбора` с `Владелец` = `Покупатель`, запись через `ПослеВводаЗначенияАдминистратором` → `ЗаписатьПолеСтрокиАРМ`.
- **Запись.** В `ЗаписатьПолеСтрокиАРМ` для заполненного `Договор`: если `Владелец` ≠ `Покупатель` записи регистра — отказ с текстом «Договор «…» не принадлежит заказчику «…»». Очистка (пустое значение) разрешена.
- **Не трогали:** закупки (`ЗакупкиДоговор`), форма выбора договоров, метаданные, роли.
- **Diff:** изменены только два метода формы; объекты/роли/интерфейс из кода — 0.
- **Приёмка UI (п.1–11):** загрузка в ИБ и чеклист — вручную на `D:\1c\test_v21` под Администратором с тестовыми контрагентами/договорами из раздела «Подготовка данных».
