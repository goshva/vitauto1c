## 5. Сценарии демо (35–40 минут)

### S1. Заявка из Excel → заказ (менеджер, 5 мин)
1. Вход `Менеджер / manager123`.
2. «Импорт» → вставить строки из Excel или загрузить `.xlsx` → предпросмотр.
3. «Создать заказ» → заказ `ЗК-0NN` и строки в списке продаж.
4. Показать коды колонок, срочность, госномер, подбор номенклатуры.
*Говорим:* ручной ввод и файл поддержаны, авто-сопоставление — доработка.

### S2. Резерв и закупка (менеджер, 7 мин)
1. Отметить строки → «Зарезервировать» (в наличии) — статус «Резервирование».
2. На недостающее — кнопка «Резервировать доступное» → авто-строка «к дозаказу».
3. «Заказ поставщику» по отмеченным закупкам → документы, статус «Заказано».
4. Канбан снабжения: «Оплачено» → «Товар в пути».

### S3. Склад: приёмка, ячейка, сборка, отгрузка (кладовщик, 8 мин)
1. Вход `Кладовщик / storekeeper123`, представление снабжения.
2. Строка «Приходуется» → выбрать ячейку → «НаСкладе» (проверено: `placed=true`).
3. «На комплектацию» → сборочный лист (печать).
4. «Готово к отгрузке» → «Отгрузить»: дата и номер → отгрузочная ведомость.
*Проверено:* отгрузка обработала 9 строк из 50 по заказу.

### S4. Возврат (менеджер/кладовщик, 4 мин)
1. Отметить отгруженные строки → «Возврат» → документ `ВР-00N`.
2. «Провести» → движения склада (`stock.move`) и статус «Возврат».
*Исправлено сегодня:* до правки проведение падало (`conn busy`, FK по партии).

### S5. Заказ-наряд механика (главный механик, 4 мин)
1. Вход `ГлавныйМеханик / chief123` → «Заказ-наряды» → создать (машина, клиент, нормо-часы).
2. «Выпуск» → печать комплекта документов.

### S6. Права и администратор (6 мин)
1. Под кладовщиком нажать действие менеджера → **403** (проверено).
2. «Запрос доступа» → админ одобряет → уведомление.
3. Админ: матрица прав, каталог (товары/услуги/машины), справочники, консоль API.
4. Показать живые уведомления (WebSocket) — вторая вкладка обновляется.
