# Gap-анализ: реализация vitauto (Go + Vue 3 + PostgreSQL) против ТЗ v3 (БТ + ФТ, 617 ч)

**Дата:** 3 ноября 2026  
**Версия:** Go-бэкенд `0.1.0`, PWA `3.5`, schema `v5`  
**Источники ТЗ:** `process.html` (45 узлов, 11 сценариев), `docs/migration/TZ.md` (ТФ1-ТФ10, ТД1-ТД8, ТР1-ТР5, ТБ1-ТБ2, ТИ1-ТИ2, ТШ1-ТШ3, ТР1-ТР4, ТН1-ТН5), `tasks/fix-open-tasks.md`, `tasks/print-notify-scope.md`, `tasks/techdebt-plan.md`, `tasks/TODO.md`

## 1. Методология

Каждый узел `process.html` и требование ТЗ v3 оценены:

| Статус | Определение |
|---|---|
| **OK** | Полностью реализовано: API-маршрут + сервис + PWA-компонент/вьюха |
| **PART** | Частично: API/сервис есть, но нет PWA-интерфейса, уведомления, печати, или реализация неполная (отсутствует ключевая ветка, авто-уведомления не срабатывают, и т.д.) |
| **NO** | Отсутствует: нет API-маршрута, сервиса, PWA-компонента или объекта БД |

## 6. Приоритеты для реализации

### Критичные пробелы (P0) — блокируют бизнес-процесс

1. **WS/уведомления** (ТР2) — `NotificationsBell` показывает накопленные, но нет реалтайм-обновлений (WebSocket `LISTEN/NOTIFY`)
2. **Обработчик outbox** (ТШ1, ТШ3) — `integration.outbox` таблица заполняется, но Go-сервис для отправки в 1С отсутствует
3. **Размещение по ячейкам (K2)** — `storage_cell` в БД есть, но нет UI; приёмка (K1) не связана с ячейками
4. **Уведомление о готовности (M11)** — отсутствует в триггере `arm.line_status_notice()`
5. **Контроль комплектации (UI M10)** — `RejectAssembly` есть, но нет кнопки в UI

### Важные пробелы (P1) — для полноценного использования

1. **Excel/CSV-парсер** (ТИ1) — M1 сейчас ручной ввод
2. **Печать: отгрузочная ведомость (M12), сборочный лист (K3)** — шаблоны есть, но нет вызова из PWA
3. **Возвраты (C1, C2)** — нет объекта `return_order`, нет UI K6/M19/M16
4. **Самовывоз (A4)** — N4, M17, K9 отсутствуют
5. **Неопознанные позиции (D1)** — M18, G8, A1 отсутствуют
6. **Виртуальный закуп (B1)** — A3 отсутствует
7. **Розыск позиции (K8)** — B1

### Низкий приоритет (P2) — ремонтная зона

1. **G1–G9** — заказ-наряды, нормо-часы, зарплатный фонд, выдача в ремонт
2. **Клиентский кабинет** (N1, N2a, N3) — пока достаточно через менеджера
