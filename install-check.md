# Проверка установки 1С — 30.09.2026

Проверено на рабочей машине после установки скриптом `install-1c.ps1` (файловый вариант).

## Итог

1С установлена, база работает. Технологический журнал не пишется: `logcfg.xml` лежит не в той папке. От прошлых запусков `install-1c-pgsql.ps1` осталась PostgreSQL.

## Что установлено и работает

- **Платформа 8.3.27.2342, 32-битная** — `C:\Program Files (x86)\1cv8\8.3.27.2342`. Дистрибутив с Яндекс.Диска (`windows_8_3_27_2342`) 32-битный. 64-битной платформы на машине нет.
- **Файловая база** — `D:\1c_bases\autoservice\1Cv8.1CD` (около 1,9 ГБ), в списке баз под именем «Автосервис» (`Connect=File="D:\1c_bases\autoservice";`).
- **Последний запуск установки** — `D:\1c\logs\install_20260929_221950.log`, закончился «ГОТОВО»:
  - база скопирована из готового `1Cv8.1CD` дистрибутива (1,8 ГБ);
  - подключено и применено расширение `АРМЗакупокИПродаж` из `АРМЗакупокИПродаж_v1.cfe`;
  - конфигуратор открыл базу.
- **Комьюнити-лицензия** — `C:\ProgramData\1C\licenses\20260929140732.lic`.
- **Служба сервера 1С (ragent)** — нет, для файлового варианта так и должно быть.

На момент проверки база была открыта в конфигураторе и в тонком клиенте с отладкой. Загружалась ли в неё v2.0 расширения, не проверено: для этого нужен конфигуратор, а он был занят.

## Проблемы

### 1. Технологический журнал не работает

- В `D:\1c\tj` нет ни одного файла.
- 32-битная платформа читает `logcfg.xml` из `C:\Program Files (x86)\1cv8\conf`. Скрипт записал его в `C:\Program Files\1cv8\conf` (значение `-LogcfgPath` по умолчанию), и там его никто не читает.
- В логе установки было предупреждение «ТЖ не дал новых файлов». Скрипт объясняет его коротким порогом по времени, но настоящая причина — неверная папка.
- Та же ошибка есть в `install-1c-pgsql.ps1`.
- **Исправление:** путь к `logcfg.xml` должен определяться по папке, куда фактически установилась платформа (`<корень 1cv8>\conf`), а сам файл нужно перенести в `C:\Program Files (x86)\1cv8\conf`.

### 2. Осталась PostgreSQL

- Установлена `PostgreSQL 15.13-1.1C(x64)`, запущена служба `postgresql-1c-15`, остались каталоги `C:\PGDATA15` и `C:\srvinfo`.
- Это следы прошлых запусков `install-1c-pgsql.ps1`. Файловый скрипт их не удаляет.
- Для файловой базы они не нужны и занимают память и место на диске.
- Удаление необратимо: база в PostgreSQL будет потеряна. Делать только по отдельному решению.

### 3. Мало места на диске C:

- На C: свободно 7,6 ГБ, на D: — 15,3 ГБ.
- При росте базы и копиях для проверок расширения (эталонная база + временные копии) места на C: не хватит. Копии лучше держать на D:.

## Прочее
